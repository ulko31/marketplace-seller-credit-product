# Marketplace Seller Credit Product

Продуктовый кейс по разработке финансового решения для селлеров маркетплейса.

Проект посвящён созданию более доступного и гибкого кредитного продукта для малого и среднего бизнеса, работающего через маркетплейсы. В рамках кейса были проанализированы рынок кредитования, потребности селлеров, предложения банков и маркетплейсов, после чего сформирована продуктовая концепция с интеграцией банка-партнёра непосредственно в экосистему маркетплейса.

## Задача

Разработать кредитный продукт для селлеров маркетплейса X, который:

- закрывает потребность в оборотном финансировании;
- снижает барьеры при получении кредита;
- учитывает сезонность и нерегулярность денежных потоков;
- делает оформление финансирования максимально простым;
- создаёт ценность одновременно для селлера, маркетплейса и банка.

## Контекст

Кредитование малого и среднего бизнеса становится менее доступным на фоне роста процентных ставок.

При этом около половины селлеров нуждаются во внешнем финансировании, но кредитными продуктами пользуется значительно меньшая доля предпринимателей.

Основные причины:

- высокие процентные ставки;
- отсутствие кредитной истории;
- сложность оформления;
- нехватка оборотных средств;
- кассовые разрывы;
- сезонность бизнеса;
- отсутствие гибких финансовых инструментов.

На этом фоне растёт спрос на альтернативные форматы финансирования, в том числе факторинг и кредитные линии.

В рамках проекта был проведён анализ:

- рынка факторинга;
- предложений российских банков;
- продуктов российских маркетплейсов;

Отдельно рассматривались:

Анализ показал, что классические кредиты становятся менее привлекательными для предпринимателей, а более гибкие финансовые инструменты набирают популярность.

Основные боли:

- сезонные пики спроса;
- высокие ставки по краткосрочным кредитам.

Потребности:

- быстрое финансирование;
- гибкие условия погашения;
- возможность закрывать кассовые разрывы.

### Селлеры с долгосрочной потребностью в финансировании

Основные боли:

- длинный цикл оборачиваемости средств;
- регулярные кассовые разрывы;
- высокая стоимость стандартных кредитов.

Потребности:

- финансирование на более длительный срок;
- кредитование на основе оборота и данных о продажах;
- гибкая схема платежей.

2. факторинг;
3. интеграция банка-партнёра в маркетплейс.

## Продуктовая концепция

Основная идея проекта — интегрировать банковские продукты напрямую в интерфейс маркетплейса.

В качестве банка-партнёра рассматривается Альфа-Банк.

Такая модель позволяет использовать данные самого маркетплейса:

- историю продаж;
- обороты;
- данные о товарах;
- информацию о поставках;
- данные из личного кабинета селлера.

Это позволяет сократить количество действий пользователя и сделать процесс кредитования более бесшовным.

## Возобновляемая кредитная линия

Кредитная линия даёт продавцу установленный лимит, которым можно пользоваться многократно.

Преимущества:

- оформление лимита один раз;
- возможность получать средства по мере необходимости;
- проценты начисляются только на фактически использованную сумму;
- после погашения лимит восстанавливается;
- возможность использовать финансирование в периоды высокого спроса;
- гибкие варианты погашения.

## Факторинг

Факторинг используется как инструмент оперативного финансирования закупок и оборотного капитала.

Основные преимущества:

- быстрое получение средств;
- возможность финансирования без классического залога;
- ускорение оборота капитала;
- финансирование закупок;
- снижение риска кассовых разрывов.

## MVP: путь пользователя

В рамках проекта был разработан MVP пользовательского пути для интеграции банковских продуктов в маркетплейс.

### Кредитная линия

Селлер может:

1. открыть калькулятор кредитной линии;
2. посмотреть доступные варианты;
3. выбрать вариант с залогом или без залога;
4. использовать товары на складе как часть обеспечения;
5. автоматически подтянуть данные о компании из личного кабинета;
6. получить рассчитанный лимит на основе данных о продажах;
7. проверить автоматически заполненные документы;
8. подписать документы электронной подписью.

Такой сценарий сокращает количество полей, которые пользователь должен заполнять вручную.

### Факторинг

Пользователь:

1. выбирает нужную поставку или закупку;
2. запускает заявку на финансирование;
3. данные о компании автоматически подтягиваются из личного кабинета;
4. система анализирует данные о продажах;
5. формируется предложение;
6. пользователь получает документы для подписания.

## Аналитика для селлера

Дополнительно была предложена аналитическая часть продукта.

В отдельном разделе пользователь может получать:

- статистику по продажам;
- рекомендации по карточкам товаров;
- аналитику эффективности;
- прогнозы поставок;

Таким образом, маркетплейс становится не только каналом продаж и источником финансирования, но и аналитической платформой для продавца.
